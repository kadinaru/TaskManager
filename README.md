# TaskManager

**Описание:**  
**TaskManager** — это приложение для управления списком задач.  
Пользователь может добавлять новые задачи, редактировать и удалять существующие, фильтровать задачи по исполнителю, названию или статусу, а также работать с разными источниками данных:  
- **Генерация** случайного списка задач,  
- **Файл** (`tasks.txt` в папке resources),  
- **База данных** SQLite (`tasks.db`).  

---

**Технологический стек:**  
- **Java 17+**  
- **JavaFX**  
- **SQLite**

## Архитектура  

Приложение реализовано по многослойной архитектуре:

- **model** — модель данных (`Task`).  
- **dao** — интерфейсы доступа к данным (`TaskDAO`) и реализации:  
  - `DbTaskDAO` — работа с SQLite  
  - `FileTaskDAO` — работа с текстовым файлом  
  - `ListTaskDAO` — генерация случайного списка задач  
- **tasklist** — графический интерфейс на JavaFX (`MainApp`, `MainController`, `TaskDialog`).  
- **TaskFactory** — фабрика для создания нужного DAO по выбранному источнику данных.

## Возможности  

- Добавление, редактирование и удаление задач.  
- Фильтрация списка по исполнителю, названию и статусу.  
- Выбор источника данных: генерация, файл или база данных.  
- Отображение задач в таблице с форматированием времени.  
- Сохранение данных в SQLite или работу с локальным файлом `tasks.txt`.

- Java: 17+
